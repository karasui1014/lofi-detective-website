シーダンス2.5 プロンプト工房

30秒ワンパス時代のプロンプトは、絵の説明ではなく香盤表です。
素材ゼロでも始められて、慣れたらフル演出まで同じ画面で作れます。

1モードを選ぶ

用意できる素材でモードが決まります。何も無くても大丈夫です。

2目的・尺・画面比

3登場人物（キャラクター定義）

視覚アンカーは3〜5個が最適。多すぎても少なすぎても顔が崩れます。
ここで作った文は毎回一字一句同じものを使うので、連作で同じ人物が保てます。

4参照マニフェスト

ファイルはここにはアップロードしません。「どの素材の何を使い、何を使わないか」だけを管理します。
出来上がったプロンプトの @Image 1 の順番どおりに、生成サイト側で素材をアップしてください。

5編集の前提

ここを書かないと全体が作り直されます。編集は20秒以下がいちばん安定します。

6初期状態（0秒の画）

人物・小道具・カメラが「開始時どこにあるか」を書きます。

7ビート表（時間割）心臓部

30秒を分割して、各区間で何が起きるかを書きます。
コツは静 → 動 → 静。1ビート＝連続した1つの主要動作、カメラの動きも1つだけ。

8終了状態（最後の画）

「見て分かる状態」で書きます。感情ではなく体の位置と向きで。

9映像（ショット・光・質感）

光（いちばん効きます）
質感・スタイル
色

10音声

記号（ ( ) < > { } 【 】 ）は自動で付きます。中身だけ書いてください。

セリフ

1本の中では言語を1つに揃えるのが安全です。短く、話者と秒数を指定してください。

11禁止事項・一貫性ロック

avoid（出したくないもの）
一貫性ロック

※ このツールは動画を生成しません。プロンプトを組み立てるだけです。生成は Dreamina / CapCut などで行ってください。
※ 入力内容はお使いの端末内（localStorage）にのみ保存され、外部に送信されることはありません。
※ 参照素材の上限（画像30・動画10・音声10）はプラットフォームにより異なります。data.js の LIMITS で変更できます。
