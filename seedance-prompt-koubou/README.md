# シーダンス2.5 プロンプト工房

Seedance 2.5（シーダンス2.5）向けの動画生成プロンプトを作るツールです。

**→ https://karasui1014.github.io/lofi-detective-website/seedance-prompt-koubou/**

30秒ワンパス時代のプロンプトは、絵の説明ではなく**香盤表**です。
このツールは、手書きだと必ず抜ける項目をUIで埋めさせて、正しい形に組み立てます。

## 2つの入口

| | かんたん | こだわり |
|---|---|---|
| 入力 | 用途・画像・ざっくり台本の3つだけ | 全項目（登場人物・ビート表・音声・境界フレーム…） |
| 向き | 素材はあるが演出は任せたい | 1カットずつ作り込みたい |

かんたんで作ってから「こだわり」に切り替えると、全部埋まった状態で続きが作れます。

### かんたんモード

1. **何を作るか選ぶ** — CM・広告 / MV / ショートドラマ / 商品紹介 / SNSショート / イメージ映像
   → 尺・画面比・光・質感・色・カメラの流れが一括で入ります
2. **画像を置く** — 役割（顔・衣装・商品・場所・色トーン・構図）を1つ選ぶだけで、
   「使う属性」と「使わない属性」が両方入ります
3. **1行ずつ台本を書く** — 行がそのままカットになります。`「かぎかっこ」`は台詞として拾います

### こだわりモード（5つのモード）

- **Lv0 おまかせ1カット** — 素材ゼロ、テキストだけ
- **Lv1 キャラ・商品を固定** — 参照画像4〜7枚。連作が作れる実用ゾーン
- **Lv2 30秒フル演出** — 素材＋コンテ＋音声設計
- **編集** — 既存動画の部分修正（「このあと延長もする」で2段階出力）
- **延長** — 前方・後方へ伸ばす

## 破綻チェッカー（V1〜V23）

生成前に事故を止めます。

- 1ビートにカメラの動きが2つ以上ある
- 参照素材に「使わない属性」が書かれていない
- 人物と参照画像の1対1対応が欠けている
- 同じ物を別角度で撮った画像に「1個だけ」宣言がない
- 「素敵な」「かっこいい」などの曖昧語 → 具体化を提案
- 1ビートに動作を詰め込みすぎ
- 台詞やキーフレームの秒数が総尺を超えている
- 境界フレームの厳密指定で比率がロックされる注意 …ほか

## 設計上の割り切り

- **動画は生成しません。** プロンプト文字列を組み立ててコピーさせるだけです。
  生成は Dreamina / CapCut などで行ってください。
- **APIは叩きません。** 公式APIの提供状況・料金・素材上限が流動的なため、
  依存しない作りにしています。上限値は `data.js` の `LIMITS` で変更できます。
- **設定値を本文に混ぜません。** 長さ・比率・解像度は創作の指示ではないので、
  「推奨設定」として別ブロックに分離しています。
- **素材ファイルは預かりません。** 置いた画像は確認用サムネイルで、生成には使われません。

## 技術

ビルド不要の静的サイトです。フレームワークも外部CDNもありません。

- 保存は `localStorage` のみ。**外部送信は一切ありません**
- 厳格なCSP（`default-src 'self'`）
- PWA対応（オフラインで動きます）

```
index.html      画面
app.js          状態管理・UI・イベント
builder.js      プロンプト組み立て
validator.js    破綻チェッカー V1〜V23
data.js         語彙辞書・上限値・用途プリセット
リセット.html    キャッシュが古いときの復旧ページ
設計図.md        調査結果と設計の記録
```

## ローカルで動かす

```bash
python3 -m http.server 8941
```

Mac なら `ローカルで確認.command` をダブルクリックでも起動します。

## 画面が古いままのときは

`リセット.html` を開いてください。古い Service Worker とキャッシュを消します。
保存した作品は消えません。
