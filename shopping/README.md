# おかいものメモ 🛒🐾

毎日のお買い物がラクになる、主婦向けの **可愛いお買い物リストアプリ**（PWA）。
サーバー不要・**端末内保存（localStorage）・ログイン不要・無料・オフライン対応**。
既存リポジトリの `stylist/` と同じ「サブフォルダ1つで完結」する流儀に合わせています。

> このフォルダは音楽サイト本体（探偵テーマ）とは独立したツールです。既存ファイルは変更していません。

---

## できること（Phase 1 / MVP）

- **買うものリスト**：追加 / 編集 / チェックで「かごに入れた（完了）」/ 削除。完了品はやさしく下へ移動。
- **予測入力（学習）**：一度書いたものは次回から候補に出ます。`⭐ いつもの` チップでワンタップ追加。単位・単価も前回値を自動補完。
- **売り場順の並び替え**：商品を自動でカテゴリ分けし、`野菜 → 肉魚 → 乳製品 → …` の売り場順に表示。店内を往復しません。（`追加順` 表示なら ▲▼ で手動並べ替え）
- **予算・合計の概算**：単価を記憶し、カゴ合計をリアルタイム表示。予算バーと、超過時のやさしい警告。
- **可愛いUI ＋ PWA**：パステル配色＋丸ゴシック（Zen Maru Gothic）＋マスコット。チェック時のご褒美演出。ホーム画面に追加してオフラインでも動作。

## ファイル構成

```
shopping/
  index.html      画面（ヘッダー＋予算バー＋いつもの＋リスト＋下部「＋追加」）
  style.css       パステルテーマ（CSS変数）＋丸ゴシック
  app.js          リストCRUD・localStorage永続化・予測学習・予算・演出
  categories.js   売り場順カテゴリ＋商品名→カテゴリの自動分類辞書
  manifest.json   PWA マニフェスト
  sw.js           Service Worker（オフライン動作）
  icon.svg        アプリアイコン／マスコット
  README.md       このファイル
```

## データの保存先（localStorage キー）

すべて端末内にのみ保存され、ブラウザ外には送信されません。

| キー | 内容 |
| --- | --- |
| `okaimono.items` | いまのリスト `[{id,name,category,qty,unit,price,checked,addedAt,order}]` |
| `okaimono.catalog` | 学習辞書（予測候補の素）`{name:{name,category,count,lastUsed,unit,price}}` |
| `okaimono.budget` | 予算（円） |
| `okaimono.settings` | 表示設定 `{sort:'aisle'|'added', reward:true}` |

## ローカルで動かす

PWA / Service Worker は `file://` では動かないため、簡易サーバーで開きます。

```bash
cd shopping
python3 -m http.server 8000
# → http://localhost:8000/ をブラウザで開く（スマホ幅でも確認）
```

## 公開（無料・ビルド不要）

静的ファイルだけなので、そのまま無料ホスティングに置けます。

- **GitHub Pages**：リポジトリを Pages 公開していれば `https://<user>.github.io/<repo>/shopping/` で開けます。
- **Cloudflare Pages**：`stylist/` と同様、リポジトリを接続して静的配信。ビルド設定は不要（出力に `shopping/` を含めるだけ）。

スマホで開いて **「ホーム画面に追加」** すると、アプリのように起動でき、オフラインでも動きます。

## 動作確認の目安

- 品を追加 → リロードしても残る（永続化）。
- 同じ品を再度打つと候補に出る／`いつもの` に並ぶ（学習）。
- 野菜・肉・日用品を混ぜて追加 → `売り場順` でカテゴリ順に並ぶ。
- 単価を入れる → 合計と予算バーがリアルタイム更新、超過で警告。
- 設定で予算を入れる／ご褒美アニメ ON・OFF。
- 機内モードでもコア機能（追加・チェック・編集）が動く。
