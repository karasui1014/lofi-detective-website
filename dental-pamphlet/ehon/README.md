# は探偵ハクちゃん ～きえた ニコニコ歯ならびの なぞ～
## 絵本風 小児矯正パンフレット（A5・全6ページ）— 完成データ

歯医者さんの待合に置く絵本風パンフを、**そのまま印刷できる形**まで組んだものです。
イラストはすべて SVG で自作（AIの文字化け・不確実さを避け、日本語と画づくりを完全制御）。

### 成果物
| ファイル | 内容 |
|---|---|
| **`ehon-A5.pdf`** | ★本命。A5・6ページの印刷用PDF（フォント埋め込み・色は印刷対応） |
| `index.html` | 同じ中身のHTML版。ブラウザで開けば閲覧でき、`Ctrl/⌘+P → PDFに保存`（用紙A5・余白なし・背景グラフィックON）でもPDF化可能 |
| `fonts/*.woff2` | 使用文字だけにサブセットした埋め込みフォント（軽量） |
| `build.py` | `index.html` を生成（SVGキャラを部品化して組版） |
| `render.py` | `index.html` → PDF（WeasyPrint）＋ 各ページPNG（検証用 `_preview/`） |

### 台割（6ページ）
1. **表紙** — は探偵ハクちゃん登場「お口の中で じけん はっせい！？」
2. **導入** — 歯ならびタウンが最近ガッタガタ…（おうちの方へ＝早期発見の価値）
3. **なぞとき** — 犯人は“クセ”（ポカンマン＝口呼吸／ベロベロ＝舌癖）
4. **解決①** — マイオブレ＋あいうべ体操（＝**マイオブレス／MFT**）
5. **解決②** — とうめいマウスピース／たよれるワイヤー（＝**マウスピース矯正／ワイヤー矯正**）
6. **大団円＋来院案内** — じけんかいけつ！＋医院情報CTA＋注意書き

各ページに、子ども向けの絵本本文と「**おうちの方へ**」の親向け訴求を併記しています。

### 医院情報の差し込み
`index.html` 内の `［ ］` プレースホルダ（医院名・住所・電話・予約・診療時間・特典・ロゴ）を
実際の情報に置き換え、`render.py` で再出力してください。ブランドカラーに寄せたい場合は
`build.py` 冒頭の配色定数（MINT/SKY/CORAL など）を変更できます。

### 印刷・入稿について（重要）
- このPDFは **RGB・塗り足し（ブリード）／トンボなし** の構成で、**オフィス／家庭プリントや
  簡易ネットプリント**にそのまま使えます。
- **本格的な商業印刷入稿**が必要な場合は、Illustrator/InDesign 等で **CMYK変換・3mm塗り足し・
  トンボ追加** を行ってください（ご希望あれば当方で別途対応可）。A5中綴じ冊子は印刷所の
  面付けに任せるのが簡単です。

### 再生成手順
```bash
python3 -m venv venv
venv/bin/pip install weasyprint pymupdf "fonttools[woff]" brotli
# 元のTTF4種を用意（Google Fonts）: M PLUS Rounded 1c Regular/Medium/Bold, Mochiy Pop One
venv/bin/python build.py full index.html
FONT_SRC=/path/to/ttf-dir venv/bin/python render.py     # → ehon-A5.pdf, _preview/p*.png
```

### フォント
M PLUS Rounded 1c ／ Mochiy Pop One（ともに SIL OFL 1.1）。`fonts/NOTICE.txt` 参照。
